# DetectoDog design reference

`prototype/Screen.dc.html` is Darcy's supplied interactive design prototype. Open it through a local web server; it depends on browser-loaded React and icon/font CDNs.

The production implementation lives in `app/`. The prototype remains the visual and copy reference, while the Expo application supplies real camera, upload, API, history, and sharing behaviour.

The source ZIP also contained a generated binary thumbnail. It is intentionally not duplicated here because it is not needed to run or implement the design.
